## Recording

The fixture-driven behavior is replayed by `cargo test`, not by `rust-anything diff`. The recorder runs each case from a temporary folder, so relative fixture paths cannot resolve there, and the default storage path would leak the recording machine's user name.

- `record-inputs.jsonl` holds the missing-file cases that `rust-anything record` replays (`--count 0`).
- `tests/fixtures/scenarios.json` is recorded by `reference/scenarios/vscode-chat-scenarios.ts` against `fixtures/vscode/`, and `tests/scenarios.rs` replays it.
- `src/lib.rs` is hand-maintained: it decodes the JSON arguments and converts the typed port's paths and errors. `rust-anything refresh` would overwrite it.

## Loop

```sh
rust-anything record .   # record what the TS code does
rust-anything build .    # build the napi-rs module
rust-anything diff .     # run the recorded cases against Rust
rust-anything shadow .   # run both in the app, log mismatches
rust-anything gate .     # fmt, clippy, tests, unsafe, API, diff
```
